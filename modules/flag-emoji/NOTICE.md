# TwemojiCountryFlags.woff2

Police embarquee par le module `flag-emoji`. Sous-ensemble de **Twemoji**
limite aux drapeaux (indicateurs regionaux + drapeaux a tags), compile par
[country-flag-emoji-polyfill](https://github.com/talkjs/country-flag-emoji-polyfill)
(TalkJS, MIT).

- Fichier repris tel quel depuis `country-flag-emoji-polyfill@0.1`
  (`dist/TwemojiCountryFlags.woff2`, 78 Ko).
- Graphismes : [Twemoji](https://github.com/jdecked/twemoji) — **CC-BY 4.0**
  (attribution : Twitter, Inc. et contributeurs).
- Code du polyfill : MIT.

Aucun appel reseau a l'execution : la police est lue depuis l'extension.
